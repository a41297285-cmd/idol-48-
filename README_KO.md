# Idol Producer 48 (아이돌 프로듀서 48)

닌텐도 DS(NDS)용 아이돌 육성 시뮬레이션 게임입니다.

## 게임 소개 및 조작법
당신은 자본금 100억 원을 가진 프로듀서입니다. 오디션을 통해 멤버를 선발하고 앨범을 발매해 최고의 아이돌 그룹으로 키워보세요!

- **방향키 (십자키)**: 스케줄 메뉴 이동
- **A 버튼**: 선택 / 결정 (진행)
- **START 버튼**: 타이틀 화면에서 시작, 게임 오버 시 재시작

## 🎮 에뮬레이터(melonDS)로 실행하는 방법
1. PC나 스마트폰에 `melonDS` 에뮬레이터를 설치합니다.
2. 압축 해제 후 생성된 `Idol_Producer_48.nds` 파일을 에뮬레이터로 엽니다 (File -> Open ROM).
3. 위 화면에서 상태를 확인하고, 아래 화면에서 스케줄을 조작하여 재미있게 플레이합니다!

## ☁️ .nds 파일이 없을 때 (GitHub로 1분 만에 자동 빌드하기)
환경 문제로 `.nds` 파일이 빌드되지 않았다면 아래 순서대로 클릭만 해서 직접 생성할 수 있습니다:
1. GitHub(github.com)에 로그인하거나 회원가입을 합니다.
2. 우측 상단의 `+` 버튼을 눌러 **New repository**(새 저장소)를 만듭니다.
3. 이 압축 파일 안에 있는 **모든 폴더와 파일**(`source`, `.github`, `Makefile` 등)을 새 저장소에 업로드(Push 또는 브라우저에 드래그 앤 드롭)하고 Commit 합니다.
4. 저장소 상단의 **Actions** 탭을 클릭합니다.
5. "Build NDS Game" 워크플로우가 자동으로 돌아가는 것을 확인합니다.
6. 빌드가 완료되면(초록색 체크 표시), 하단 **Artifacts** 영역에서 `Idol_Producer_48_ROM`을 클릭하여 `.nds` 파일을 다운로드합니다!
7. 혹시라도 에러가 발생한다면, 에러 메시지를 그대로 복사해서 AI에게 붙여넣고 해결 방법을 물어보세요!

## 🛠 설정값을 바꿔서 게임 수정해보기
`source/main.c` 파일을 메모장이나 코드 에디터로 열어보세요.
파일 맨 윗부분에 아래와 같은 설정값이 모여있습니다.

```c
int STARTING_FUNDS = 10000;  // 시작 자금
int AUDITION_COST = 500;     // 오디션 진행 비용
```
이 숫자들을 원하는 대로 바꾸고 저장한 뒤, 다시 GitHub에 업로드하여 빌드하면 난이도가 바뀐 나만의 버전을 즐길 수 있습니다.

## ⚠️ AI가 임의로 정한 부분 목록
방대한 기획서를 바탕으로, 확실하게 닌텐도 DS 기기에서 60fps로 버그 없이 구동되는 "작은 게임" 완성을 위해 일부 기획을 심플하게 반영했습니다.
1. **한글 출력 배제**: NDS 기본 라이브러리(libnds)는 한글 폰트를 내장하지 않아 한글 입력 시 글자가 깨지는 현상이 발생합니다. 안정성을 위해 모든 UI를 **영어/숫자**로 작성했습니다.
2. **그래픽/UI 구성 단순화**: 외부 이미지 도구 변환 이슈를 방지하고 NDS 콘솔 본연의 느낌을 살리기 위해, 상/하단 듀얼 스크린 텍스트 렌더링 엔진을 활용했습니다. 위 화면은 실시간 이벤트 로그 및 스탯, 아래 화면은 조작 메뉴로 구성했습니다.
3. **멤버 및 스케줄 축소**: 도트 생성 및 1000가지 이름 등은 용량 및 복잡성을 넘어서므로, 랜덤 영문 이니셜 및 스탯 기반의 텍스트 매니지먼트로 핵심 루프(오디션-앨범-콘서트-정산)를 구현했습니다.
